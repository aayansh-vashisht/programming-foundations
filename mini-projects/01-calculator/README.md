# Command-Line Calculator

A CLI calculator built with Python 3, demonstrating modular functions, exception handling, and input validation.

## Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Input validation for non-numeric user inputs (`ValueError` handling)
- Division-by-zero protection (`ZeroDivisionError` handling)
- Interactive loop allowing continuous calculations until explicit exit

## How to Run
```bash
python3 calculator.py
